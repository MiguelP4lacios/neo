# Runbooks

Living procedures — `RUN-<descriptive-topic>.md`, no date in the name, edited in place.

A runbook earns its place when a procedure will be repeated by someone else (or by you, in three months, having forgotten the traps). Shape:

```markdown
# RUN — <what it does>

**Area:** <area> · **Date:** <first written> · **First used for:** <context>

**Read when:** <the situation that calls for it>

## Before you start
<preconditions, what to check first, what can bite>

## Run it
<exact commands>

## Verify
<how to prove it worked — not "it returned OK">

## If it goes wrong
<recovery>
```

Index every runbook in `../README.md` under **Runbooks**.
